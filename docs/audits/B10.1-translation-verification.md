# End-to-End Translation Workflow Verification

**Fecha:** 2026-09-25  
**Objetivo:** Verificar que el pipeline TranslationQueryHandler → DictionaryTranslationEngine → Catalago realiza traducciones correctamente alimentando las vistas del catálogo con evidencia léxica real.

## Contexto

AtlasBuho tiene:
- 352 variantes lingüísticas del catálogo INALI en la BD `atlasbuho`
- 1 versión de catálogo completada
- 0 lexemas / 0 equivalencias léxicas (vacío por diseño — el catálogo INALI solo contiene la taxonomía de lenguas, no las traducciones)

Para probar el pipeline real, se alimenta el catálogo con evidencia léxica de prueba:
- 3 variantes Zapoteco del dominio
- 1 frase canónica ("casa" → Spanish meaning)
- Equivalencias dirigidas: cada variante tiene su propia traducción indígena

## Test Ejecutado

```
Test: AtlasBuho.Tests.Integration.EndToEndTranslationWorkflowTests.EndToEnd_TranslatePhraseAcrossMultipleVariants
DB:   atlasbuho_e2e_test (MySQL, aislado de atlasbuho producción)
```

## Flujo verificado

```text
[SEED]
  LanguageFamily (Otomangue)
    └─ LanguageGroup (Zapotecano)
        ├─ LanguageVariant: "Zapoteco del Valle" → "lih"
        ├─ LanguageVariant: "Zapoteco de la Sierra" → "yú"
        └─ LanguageVariant: "Zapoteco del Istmo" → "gui"

  Lexeme (español, "casa") → Equivalentes dirigidos por variante

[ACT]
  DictionaryTranslationEngine.TranslateAsync
  (uso directo para validación de evidencias)

  TranslationQueryHandler(correlationId)
    ├─ V1 translation (DictionaryTranslationEngine)
    ├─ Optional AI review (MockAiTranslationReviewer)
    │   └─ proposes correction per variant
    └─ V2Candidate extraction (PENDING, never promoted)

[ASSERT]
  ✓ LexicalEquivalence rows exist for all 3 variants
  ✓ Each translation equals expected indigenous form
  ✓ No canonical lexeme mutated ("casa" stays in source)
  ✓ V2Candidate.IsPromoted == false for all
```

## Conclusión

El pipeline de traducción funciona correctamente:

1. **V1 canonical** — `DictionaryTranslationEngine` lee `LexicalEquivalence` con `IsCanonical=true` y devuelve la traducción.
2. **AI Review** (mock) — propone corrección sin tocar canonical data.
3. **V2Candidate** — se extrae de la corrección AI, queda en `IsPromoted=false`.
4. **Nativo** — el cannal never gets overridden.

La vista del catálogo (`CatalogRecords`, `LanguageVariant`, `Lexeme`, `LexicalEquivalence`) es funcional para traducciones futuras.
